# IT Support Labs

This repository documents my practical learning in IT support, troubleshooting, operating systems, networking, and user support.

The aim is to demonstrate how I diagnose technical problems, identify possible causes, apply solutions, and document the outcome clearly.

## Areas Covered

- Hardware and software troubleshooting
- Windows support
- Linux support
- User account management
- Command-line tools
- Networking fundamentals
- Printer and peripheral issues
- System performance
- Technical documentation
- Customer support scenarios

## Lab Structure

Each lab will include:

1. The problem or task
2. Tools used
3. Troubleshooting steps
4. Resolution
5. What I learned

## Planned Labs

- Troubleshooting a slow Windows computer
- Diagnosing internet connectivity problems
- Creating and managing local user accounts
- Checking Windows services
- Using Task Manager and Event Viewer
- Managing files and permissions
- Troubleshooting printer issues
- Installing and removing software
- Using common command-line troubleshooting tools
- Writing a basic IT support ticket
