# Lab 01 - Troubleshooting a Slow Windows Computer

## Objective

Diagnose and improve the performance of a Windows computer experiencing slow startup and poor responsiveness.

---

## Symptoms

- Slow boot time
- Applications taking a long time to open
- High CPU usage
- Frequent system freezing

---

## Tools Used

- Task Manager
- Startup Apps
- Disk Cleanup
- Windows Update
- Command Prompt
- Event Viewer

---

## Troubleshooting Steps

### Step 1
Opened Task Manager and checked CPU, Memory and Disk usage.

### Step 2
Reviewed Startup Apps and disabled unnecessary applications.

### Step 3
Ran Disk Cleanup to remove temporary files, internet cache, DirectX shader cache, and Delivery Optimisation files.

### Step 4
Checked Windows Update and confirmed the system was already up to date with no pending updates.

### Step 5
Reviewed Event Viewer for system errors.

### Step 6
Restarted the computer and monitored performance.

---

## Result

Reviewed system performance using Task Manager, Startup Apps, Disk Cleanup, Windows Update, and Event Viewer. The system was up to date, temporary files were removed, and the computer restarted successfully after the maintenance checks.

---

---

## Lessons Learned

A structured troubleshooting approach makes it easier to identify the root cause of performance issues and document the resolution clearly.
