# Lab 01 - Troubleshooting a Slow Windows Computer

## Objective

Diagnose and improve the performance of a Windows computer experiencing slow startup and poor responsiveness.

---

## Symptoms

- Slow boot time
- Applications taking a long time to open
- High CPU usage
- Frequent system freezing

---

## Tools Used

- Task Manager
- Startup Apps
- Disk Cleanup
- Windows Update
- Command Prompt
- Event Viewer

---

## Troubleshooting Steps

### Step 1
Opened Task Manager and checked CPU, Memory and Disk usage.

### Step 2
Reviewed Startup Apps and disabled unnecessary applications.

### Step 3
Ran Disk Cleanup to remove temporary files.

### Step 4
Checked Windows Update and installed available updates.

### Step 5
Reviewed Event Viewer for system errors.

### Step 6
Restarted the computer and monitored performance.

---

## Result

System startup time improved and overall responsiveness increased after removing unnecessary startup applications and cleaning temporary files.

---

## Skills Demonstrated

- Windows troubleshooting
- Performance optimisation
- System diagnostics
- Documentation
- Problem solving

---

## Lessons Learned

A structured troubleshooting approach makes it easier to identify the root cause of performance issues and document the resolution clearly.
