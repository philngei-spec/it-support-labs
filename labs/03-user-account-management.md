# Lab 03 - User Account Management

## Objective

Demonstrate common Windows user account management tasks including creating users, changing passwords, managing account types, and verifying user information.

## Problem

Practice creating and managing local user accounts.

## Steps Performed

### Step 1. 

Opened Computer Management

### Step 2

Navigated to Local Users and Groups > Users

### Step 3 

Created a new local user named 'Lab User'

### Step 4

Set a password for the account.

### Step 5

Saved the new user account.

### Step 6

Opened Command Prompt as Administrator.

### Step 7

Ran the following command:

```cmd
net user
```
### Step 8

Verified that LabUser appeared in the list of local users.


## Verification

Ran `net user` in command prompt and confirmed that the newly created `LabUser` account appeared in the list of local user accounts.

Windows Server Administration, Local User Management, Command Prompt, Documentation.
